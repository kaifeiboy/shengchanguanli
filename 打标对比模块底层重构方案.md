# 打标对比模块底层重构方案

## 重构目标与原则

### 核心目标
- **通用性**：非特别情况不针对单一产品做单独优化
- **准确性**：从底层提升识别和匹配准确性
- **安全性**：不影响平台及其他模块运行
- **可维护性**：架构清晰，便于后续扩展

### 重构范围
```
照片上传 → 处理识别 → 块图OCR识别 → 最终匹配标示
```

### 安全策略
- 本模块可暂停生产
- 其他模块正常运行
- 渐进式重构，可随时回滚

## 当前架构问题分析

### 现有架构
```
前端H5 → DrawingService.cs → OcrService.cs → ocr_worker.py → ocr_cli.py
                                              ↓
                                        RapidOCR单一模型
```

### 核心问题
1. **架构分散**：C#和Python混合，职责不清
2. **模型单一**：仅依赖RapidOCR，缺乏容错能力
3. **匹配复杂**：多种匹配算法，针对特定产品优化
4. **质量无保证**：缺乏统一的质量评估和改进机制
5. **扩展困难**：新增产品需要修改多处代码

## 核心组件重构

### 1. UniversalOcrService (统一OCR服务)

**职责**：提供统一的OCR接口，内部屏蔽多模型复杂性

```csharp
public class UniversalOcrService
{
    private readonly MultiModelOcrEngine _ocrEngine;
    private readonly QualityAssurance _qualityAssurance;
    private readonly AdaptivePreprocessor _preprocessor;
    
    public OcrResult Recognize(string imagePath)
    {
        // 1. 自适应预处理
        var preprocessed = _preprocessor.Process(imagePath);
        
        // 2. 多模型识别
        var results = _ocrEngine.RecognizeAll(preprocessed);
        
        // 3. 质量评估
        var quality = _qualityAssurance.Evaluate(results);
        
        // 4. 结果融合
        return _ocrEngine.FuseResults(results, quality);
    }
    
    public BatchOcrResult BatchRecognize(List<string> imagePaths)
    {
        // 批量处理，并行优化
        return _ocrEngine.RecognizeBatch(imagePaths);
    }
}
```

### 2. MultiModelOcrEngine (多模型引擎)

**职责**：管理多个OCR模型，实现结果融合

```python
class MultiModelOcrEngine:
    def __init__(self):
        # 加载多个OCR模型
        self.models = {
            'rapidocr': RapidOCR(),
            'paddleocr': PaddleOCR(use_angle_cls=True, lang='ch'),
            'tesseract': TesseractEngine()
        }
        
        # 融合策略引擎
        self.fusion_engine = ResultFusionEngine()
    
    def recognize_all(self, image_path):
        """用所有模型识别，返回多个结果"""
        results = {}
        for name, model in self.models.items():
            try:
                result = model(image_path)
                results[name] = result
            except Exception as e:
                # 记录错误，但继续其他模型
                self.log_error(name, e)
        
        return results
    
    def fuse_results(self, results, quality_assessment):
        """融合多个模型的结果"""
        return self.fusion_engine.fuse(results, quality_assessment)

class ResultFusionEngine:
    def fuse(self, results, quality):
        """通用融合策略，不针对特定产品"""
        
        # 策略1: 置信度加权
        weighted = self.weight_by_confidence(results, quality)
        
        # 策略2: 多数投票
        voted = self.majority_voting(results)
        
        # 策略3: 一致性验证
        consistent = self.consistency_check(results)
        
        # 选择最佳结果
        return self.select_best([weighted, voted, consistent])
    
    def weight_by_confidence(self, results, quality):
        """基于置信度的加权融合"""
        weights = quality['confidences']
        text_pool = []
        
        for (model_name, result), weight in zip(results.items(), weights):
            if result and result.get('text'):
                text_pool.append((result['text'], weight))
        
        # 加权合并
        return self.merge_weighted(text_pool)
```

### 3. AdaptivePreprocessor (自适应预处理)

**职责**：通用图像预处理，参数自适应

```python
class AdaptivePreprocessor:
    def process(self, image_path):
        """自适应预处理流程"""
        image = cv2.imread(image_path)
        
        # 1. 分析图像特征
        features = self.analyze_image(image)
        
        # 2. 根据特征选择预处理策略
        strategy = self.select_strategy(features)
        
        # 3. 执行预处理
        processed = self.apply_strategy(image, strategy)
        
        return processed
    
    def analyze_image(self, image):
        """分析图像特征"""
        return {
            'noise_level': self.estimate_noise(image),
            'brightness': self.estimate_brightness(image),
            'contrast': self.estimate_contrast(image),
            'blur_level': self.estimate_blur(image),
            'text_regions': self.detect_text_regions(image)
        }
    
    def select_strategy(self, features):
        """根据特征选择策略 (通用算法，不针对特定产品)"""
        strategy = {}
        
        # 自适应去噪
        if features['noise_level'] > 0.1:
            strategy['denoise'] = 'strong'
        elif features['noise_level'] > 0.05:
            strategy['denoise'] = 'medium'
        else:
            strategy['denoise'] = 'light'
        
        # 自适应对比度
        if features['contrast'] < 0.3:
            strategy['enhance'] = 'strong'
        elif features['contrast'] < 0.6:
            strategy['enhance'] = 'medium'
        else:
            strategy['enhance'] = 'none'
        
        return strategy
    
    def apply_strategy(self, image, strategy):
        """应用预处理策略"""
        processed = image.copy()
        
        # 去噪
        if strategy['denoise'] == 'strong':
            processed = cv2.fastNlMeansDenoisingColored(processed, None, 10, 10, 7, 21)
        elif strategy['denoise'] == 'medium':
            processed = cv2.bilateralFilter(processed, 9, 75, 75)
        elif strategy['denoise'] == 'light':
            processed = cv2.GaussianBlur(processed, (3, 3), 0)
        
        # 对比度增强
        if strategy['enhance'] == 'strong':
            processed = self.clahe_enhance(processed, clip_limit=3.0)
        elif strategy['enhance'] == 'medium':
            processed = self.clahe_enhance(processed, clip_limit=2.0)
        
        return processed
```

### 4. PhotoProcessor (通用照片处理)

**职责**：统一照片处理逻辑，替代现有的复杂匹配

```csharp
public class PhotoProcessor
{
    private readonly UniversalOcrService _ocrService;
    
    public PhotoProcessingResult ProcessPhoto(IFormFile photo, int drawingId)
    {
        // 1. 保存照片
        var savedPath = SavePhoto(photo);
        
        // 2. 通用OCR识别 (不针对特定产品)
        var ocrResult = _ocrService.Recognize(savedPath);
        
        // 3. 提取通用特征 (型号、电话等，但不依赖特定格式)
        var features = ExtractUniversalFeatures(ocrResult);
        
        // 4. 获取对应的图块信息
        var blocks = GetDrawingBlocks(drawingId);
        
        return new PhotoProcessingResult
        {
            Features = features,
            Blocks = blocks,
            OcrResult = ocrResult
        };
    }
    
    private Dictionary<string, string> ExtractUniversalFeatures(OcrResult ocrResult)
    {
        // 通用特征提取，不针对特定产品格式
        var text = ocrResult.Text;
        var features = new Dictionary<string, string>();
        
        // 提取字母数字组合 (通用型号模式)
        var modelMatch = Regex.Match(text, @"[A-Za-z]{2,}-?[A-Za-z0-9]*[0-9]");
        if (modelMatch.Success)
            features["model"] = modelMatch.Value;
        
        // 提取电话号码 (通用电话模式)
        var phoneMatch = Regex.Match(text, @"[0-9]{3,4}[-\s]?[0-9]{7,8}");
        if (phoneMatch.Success)
            features["phone"] = phoneMatch.Value;
        
        // 提取所有数字序列
        var numbers = Regex.Matches(text, @"\d{2,}");
        features["numbers"] = string.Join(",", numbers.Cast<Match>().Select(m => m.Value));
        
        return features;
    }
}
```

### 5. BlockMatcher (通用块匹配)

**职责**：通用匹配算法，不针对特定产品

```csharp
public class BlockMatcher
{
    public BlockMatchResult Match(PhotoProcessingResult photoResult)
    {
        var photoFeatures = photoResult.Features;
        var blocks = photoResult.Blocks;
        
        // 通用匹配算法
        var scores = new List<BlockScore>();
        
        foreach (var block in blocks)
        {
            var blockFeatures = ExtractBlockFeatures(block);
            var score = CalculateUniversalScore(photoFeatures, blockFeatures);
            scores.Add(new BlockScore(block.Index, score));
        }
        
        // 选择最佳匹配
        var bestMatch = scores.OrderByDescending(s => s.Score).FirstOrDefault();
        
        return new BlockMatchResult
        {
            BestBlockIndex = bestMatch?.BlockIndex ?? -1,
            Score = bestMatch?.Score ?? 0,
            MatchStatus = DetermineMatchStatus(bestMatch?.Score ?? 0),
            AllScores = scores
        };
    }
    
    private double CalculateUniversalScore(Dictionary<string, string> photoFeatures, 
                                           Dictionary<string, string> blockFeatures)
    {
        double totalScore = 0;
        int featureCount = 0;
        
        // 特征匹配 (通用逻辑)
        foreach (var feature in photoFeatures.Keys)
        {
            if (blockFeatures.ContainsKey(feature))
            {
                var similarity = CalculateSimilarity(photoFeatures[feature], blockFeatures[feature]);
                totalScore += similarity;
                featureCount++;
            }
        }
        
        // 文本相似度 (通用算法)
        var textSimilarity = CalculateTextSimilarity(photoFeatures["text"], blockFeatures["text"]);
        totalScore += textSimilarity * 2; // 文本相似度权重更高
        featureCount += 2;
        
        return featureCount > 0 ? totalScore / featureCount : 0;
    }
    
    private double CalculateSimilarity(string str1, string str2)
    {
        // 通用相似度算法 (编辑距离)
        var distance = LevenshteinDistance(str1, str2);
        var maxLength = Math.Max(str1.Length, str2.Length);
        return maxLength > 0 ? 1.0 - (double)distance / maxLength : 1.0;
    }
}
```

## 安全保障措施

### 1. 渐进式重构
- 每个阶段独立验证
- 可随时回滚到上一阶段
- 保持旧代码并行运行

### 2. 隔离测试
- 新旧系统并行运行
- A/B测试验证效果

- 保持现有API接口不变
- 内部实现透明替换
- 其他模块无感知

### 4. 监控告警
- 实时监控新系统指标
- 异常自动告警
- 快速回滚机制

这是一个系统性的底层重构方案，从根本上解决通用性和准确性问题，不针对单一产品，通过技术升级实现整体提升。
