## 三、冗余计算步骤分析

### 3.1 已识别的冗余计算

#### 3.1.1 OCR 重复调用
**问题**：
- `diff_visualizer.py` 和 `photo_registration.py` 都独立调用 OCR
- 同一张图片可能被 OCR 多次

**影响**：性能浪费，增加处理时间

**优化建议**：
```python
# 建议：创建 OCR 缓存层
_ocr_cache = {}  # {(image_path, timestamp): ocr_result}

def get_ocr_result(image_path):
    cache_key = (image_path, os.path.getmtime(image_path))
    if cache_key not in _ocr_cache:
        _ocr_cache[cache_key] = _ocr_image(image_path)
    return _ocr_cache[cache_key]
```

#### 3.1.2 重复的文本匹配逻辑
**问题**：
- `_texts_match_strict` 在多个文件中重复实现
- `_norm_text` 函数在多处重复定义

**影响**：代码维护成本高，容易出现不一致
