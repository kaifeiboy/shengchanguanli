## 二、共享面排查（改动前必做）
1. 若改动涉及被其它模块共用的符号（如 `OcrService.CreatePythonPsi`、公共样式、公共 JS 函数），先 `grep` 引用确认：
   - 只「被调用」、不被本改动修改 → 安全；
   - 若需修改其签名/行为 → 视为影响其它模块，停下来与用户确认，不得擅自改。
2. `defect_history.py` 仅被本模块 `DefectHistoryService` 通过 `FindScript` 调用，确认无其他模块引用后再改。

## 三、真实环境自检（每次升级必做，缺一项不得提交）
> 真实运行实例：Kestrel `http://127.0.0.1:5000`（生产），`Platform.exe` 由 SYSTEM 计划任务 `SCG_Platform` 托管。

### 3.1 改动类型 → 生效方式
| 改动 | 生效方式 | 是否需重建 |
|---|---|---|
| 仅 `defect_history.py`（Python） | 子进程每次调用加载最新，即时生效 | 否 |
| 仅 `index.html`（前端） | 静态文件，下次请求即生效（浏览器可能缓存，校验用 `v=`/无缓存） | 否 |
| `DefectHistoryService.cs`/`Module.cs`（C#） | 需重建并重启服务 | 是 |

### 3.2 C# 重建与重启（如改动 C#）
1. `Stop-ScheduledTask SCG_Platform`（PowerShell，SYSTEM 任务）。
2. `dotnet build -c Debug`（本机 SDK `C:\Program Files\dotnet\dotnet.exe`；沙箱会拦截 .NET 写盘，须 `dangerouslyDisableSandbox:true`，并 `rm -rf obj/Debug bin/Debug` + `-p:UseSharedCompilation=false`）。
3. `Start-ScheduledTask SCG_Platform`。
4. **进程加载校验**：确认 `Platform.exe` 启动时间晚于所改 `.cs`/`.py` 文件的 mtime；否则重启无效，结论不可信。
