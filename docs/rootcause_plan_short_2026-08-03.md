## 🎯 三条根治路线

### 方案 A：规则收敛 + 重切（**3-5 天，根治 4/5 根因**）
- **做法**：合并 3 个独立过滤函数 → `_is_business_garbage(text, has_anchor)`；保留 v19.36/19.37 关键修复；全量 22 图重切（清空历史 DB Icons 污染）
- **风险**：低。保留 27 版沉淀的 3 个高价值规则
- **根治**：①+③+⑤ 全部；④ 部分（图标 7 层保留 3 层）

### 方案 B：方案 A + 业务等价词典（**A + 3h人工 + 2 天代码，根治 5/5 根因**）
- **做法**：在 A 基础上加 22 图产品码/序列号/规格等价词典（人工 3 小时整理，`model/business_equivalence.py` 持久化），匹配前查表同义即绿
- **风险**：中。词典靠人工，漏标需回归补
- **根治**：A 全部 + ② OCR 漏读有词典兜底

### 方案 C：架构级重写（**2-3 周，完全重测，根治 5/5 根因 + 长期可扩**）
- **做法**：OCR/图标/匹配三段解耦为独立 pipeline；DB 作为 ground truth（含人工锚点）；废弃所有含糊字段
- **风险**：高。新测试套件 + 22 图人工金标准标注 1-2 天
- **根治**：结构性根治，后续加新图/新产品不触发打地鼠
